## 確認した動作

- PC貸与テンプレートから業務カテゴリ、セクション、補足、条件付き日付・数値・複数選択を設定できる。
- 日付の範囲外・数値の範囲外を入力試験で拒否し、許可した数値0と複数選択を保持する。
- 一時貸出の場合だけ必須の返却日を表示する。標準貸与へ変更すると返却日を除き、再表示しても旧値が復活しない。
- 入力試験・Enterでは業務書込み0。保存フォームのFormDataと実送信payloadへ試験値が混入しない。
- 保存中は入力試験が無効になる。保存したカテゴリ・セクション・質問・保存キーがAPIの保存結果と一致する。
- 作成した合成下書きだけを1回公開し、一般利用者が業務カテゴリで探せる。旧target URLは模擬対象を絞り込み、業務カテゴリとは独立して動く。
- 一般利用者が補足・セクションを見ながら入力し、日付・数値0・複数選択を含む申請を1件送信できる。
- 申請snapshotに公開版の定義・カテゴリ・セクションが残り、数値0はnumber、複数選択は配列で保存される。非表示の返却日は保存されない。再読込でも確認できる。
- 新規編集・利用者フォームでキーボード、ID重複、375px表示を確認した。axeは新規編集desktop/mobile、利用者フォームdesktop/mobile、申請確認desktopの5画面。

WebKitの最初のrunは下書き作成と公開まで成功したが、利用者フォームで理由欄が空のままnative検証に止まり、申請POSTは0だった。フォームの初回入力前にhydration後の冪等キーと有効な申請ボタンを待つよう検証ツールを修正した。保存済み公開アイテムを読み取り照合し、同じ合成アイテムの利用者部分だけを再開して成功した。追加の下書き作成・公開は0。`webkit/summary.json`の`recovery`へ記録している。
