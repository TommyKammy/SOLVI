# WP-P2-UIX-030 実行記録

- 日付: 2026-11-10
- ブランチ: `wp/WP-P2-UIX-030`
- 対象: 左レールメニューの開閉と重なり修正
- 変更範囲: `AppFrame.tsx` と `freshservice.css` のみ

## 1. 原因

フライアウトの表示をCSSの`:hover`と`:focus-within`に任せていた。
メニュー内のリンクをクリックすると、そのリンクにフォーカスが残る。
その状態で別のレール項目へホバーすると、

- 前の項目: `:focus-within`で開いたまま
- 新しい項目: `:hover`で開く

の2つが同時に表示され、前のメニューが新しいメニューに重なっていた。

## 2. 修正

- フライアウトの開閉を`openGroup`状態で管理し、同時に1つだけ開くようにした。
- マウスでレール項目またはメニュー項目をクリックしたら、フライアウトを閉じてフォーカスを外す。
- キーボード操作では、フォーカスがメニュー内にある間は開いたままにする。
- 外側クリック、Escape、ページ遷移で閉じる。
- モバイルの常時表示メニューは従来どおり。
