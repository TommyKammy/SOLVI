# コントラスト比(11.3 Design System §4)

`apps/web/src/app/freshservice.css` の `light-dark()` 定義から計算した。本文・補足文字は 4.5:1 以上を満たす。

| 組み合わせ | ライト | ダーク | 基準 |
|---|---:|---:|---|
| 本文 / 面 (`--ink` / `--surface`) | 16.91:1 | 14.76:1 | 4.5:1 |
| 本文 / カード (`--ink` / `--panel`) | 16.21:1 | 13.72:1 | 4.5:1 |
| 補足 / 面 (`--muted` / `--surface`) | 5.98:1 | 6.91:1 | 4.5:1 |
| 補足 / カード (`--muted` / `--panel`) | 5.73:1 | 6.42:1 | 4.5:1 |
| サイドバー文字 / 背景 (`--side-ink` / `--side`) | 12.09:1 | 12.83:1 | 4.5:1 |
| サイドバー文字 / ホバー (`--side-ink` / `--side-hover`) | 11.00:1 | 10.68:1 | 4.5:1 |
| サイドバー文字 / 現在地 (`--side-ink` / `--side-current`) | 9.97:1 | 9.24:1 | 4.5:1 |
| サイドバー補足 / 背景 (`--side-muted` / `--side`) | 4.51:1 | 6.22:1 | 4.5:1 |

- サイドバーの件数は、通常の面では `--side-muted` / `--side-brand` / `--danger` を使い、ホバー・現在地の面では `--side-ink` に切り替える。現在地の面で `--side-muted` を使うと 3.72:1(ライト)/4.48:1(ダーク)になるため。
- 0件の件数は強調色(ブランド・危険)を付けない。0は異常ではないため。
