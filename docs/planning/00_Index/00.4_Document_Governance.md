# Document Governance

## 文書状態

- `draft`：検討中。実装根拠に使用不可
- `baseline`：計画基準。Issue化可能
- `accepted`：決定済み。変更にはADRまたはDecision Recordが必要
- `superseded`：後継文書あり。Issue化禁止
- `archived`：履歴保持のみ

## 更新規則

- 要求変更はRTM、WP、Testを同じ変更で同期する。
- アーキテクチャ変更はADRを先に更新する。
- UI変更は画面一覧、User Story、Accessibility観点を同期する。
- 空ノート、同一テンプレートの大量複製を禁止する。
- 各WPに固有の成果物、受入基準、依存、検証方法、Codex promptを持たせる。
