# Start Here

SOLVIは、Freshserviceで実際に利用している範囲を中心に、ユーザーポータル・チケット・ナレッジ・申請承認・Okta/Entra自動化・資産・変更・AI支援を内製するプロジェクトです。

## 現在地

| 項目 | 状態 |
|---|---|
| 製品名 | **SOLVI(ソルヴィ)** |
| 位置付け | AIネイティブITSM / 将来のEnterprise Service Management基盤 |
| UI方針 | 一般社員は「リクエスト」「インシデント報告」の二導線。管理者は高密度な業務UI |
| 開発方法 | Codex app中心。人間が設計・セキュリティ・受入を承認 |
| 実装状態 | 未着手。最初の対象は`WP-P0-GOV-001` |
| 設計正本 | Phase 0/1に必要な範囲は確立済み。Phase 2以降のWPは各Phase開始2週間前に実体化 |

## 最初の成功条件(縦切りPoC)

テストユーザがOkta SSOでログインし、アクセス申請を送り、上司とIT担当が承認し、SOLVI Runが許可済みのOktaグループへ**一度だけ**追加し、その結果がチケット・Workflow・監査に残ること。

この一連の流れが、SOLVIの中核([[ADR-0006_Privileged_Executor_Separation]]・[[02.16_Executor_Command_Contract]]・[[02.17_Audit_Event_Catalog]])をすべて通過します。
