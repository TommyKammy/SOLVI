# Design System

> [!note] status: baseline
> 採用した操作式モックアップの共通表示を [[WP-P2-UIX-052]] で反映した。

## 1. 概要

UIの見た目の正本。採用した第1〜8段階の画面例は `assets/ui/SOLVI_Operations_Mockup.html`。白い本文、淡い青灰色のサイドバーとカード、1pxの境界線を使う。業務の操作、権限、表示する実データは要求と各WPに従う。

各WPは本書のトークン名を参照する。値をWPやコードへ書き写して独自に変えない。

## 2. 対象範囲

- 色(ライト/ダーク)
- 文字
- 角丸・線・余白
- アプリシェルの寸法
- 状態の表し方(期限・優先度)
- テーマ切替

## 3. 対象外

- 個別画面の情報配置(各WPで定める)
- 他社製品のロゴ・名称・画像の利用
- Webフォントの読み込み([[WP-P2-SEC-025]] のCSPを緩めないため)

- 文字色と背景色の組み合わせは、両テーマでWCAG 2.2 AAのコントラスト比(本文4.5:1)を満たすこと。満たさない組み合わせが見つかったら、本書の値を直してから実装する。
- 色だけで意味を伝えない。期限超過・優先度は文字でも示す。
- 左サイドバーの件数は通常 `--side-muted`、強調は `--side-brand`、期限超過は `--danger` で表す。ホバー・フォーカス・現在地の件数は `--side-ink`。

## 5. 文字

- 書体は `-apple-system, BlinkMacSystemFont, "Hiragino Sans", "Yu Gothic UI", "Noto Sans JP", sans-serif`。端末の書体を使う。
- 本文は0.875rem（14px）、行高1.65。補足・パンくずは0.75rem（12px）。
- ページ見出しは2rem（32px）。画面幅34rem以下では1.75rem（28px）。節見出しは1.125rem（18px）、小見出しは0.875rem（14px）。見出し行高は1.4、ページ見出しの字間は−0.027em、節見出しは−0.015em。
- 業務シェルの現在地は上部バーのパンくずに集約する。モバイルでも現在の画面名を表示する。パンくずと重複する本文の画面名は支援技術向けの見出しとして保持し、定型説明は省く。レコード名、節見出し、注意・エラー、依頼者ポータルの見出しは本文に表示する。
- 本文400、通常操作500、主操作650、見出し700、現在地750を目安にする。
- 数字の列は `font-variant-numeric: tabular-nums` で桁を揃える

## 6. 形と寸法

| 項目 | 値 |
|---|---|
| 角丸 | 8px（行・ボタン・切替）、12px（カード） |
| 影 | 使わない |
| 線 | 1px、`--line`(サイドバー内は `--side-line`) |
| 左サイドバー | 幅14rem（224px）。画面幅63rem以下では開閉式 |
| 上部バー | 最小高4rem（64px） |
| 本文上部の余白 | 2.125rem（34px）。画面幅48rem以下では1.5rem（24px） |
| フォームと主要な操作列 | 操作高2.5rem（40px）、粗いポインターで2.75rem（44px）。ラベルと操作は折り返し可能 |
| 本文の左右余白 `--fs-content-gutter` | 各32px。ビューポート幅1100px以下では24px、600px以下では20px |
| 本文枠の最大幅 `--fs-content-max` | 1536px。左右余白を含めて本文枠をコンテンツ領域の中央に配置する |

担当者シェルと依頼者ポータルは同じコンテンツ左右余白を使う。操作列の間隔は0.5rem、絞り込みパネルの内側は0.875rem、ページの上部見出しと次の区画の間隔は1.25remを目安にする。入力欄の枠は両テーマで3:1を満たす `--fs-control-border` を使用する。

## 7. テーマ切替

- 初期値はOSの設定(`prefers-color-scheme`)に従う。
- 利用者が選んだテーマはブラウザに保存する。読み書きに失敗しても表示は壊さない。
- サーバーには保存しない(端末ごとの設定)。
- ダークテーマは、まずアプリシェルと本書のトークンを使う部分に適用する。各画面のCSS Modulesに残る固定色は、後続WPでトークンへ置き換える。
