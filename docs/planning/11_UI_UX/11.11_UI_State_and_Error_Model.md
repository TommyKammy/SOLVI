# UI State and Error Model

> [!warning] この文書は骨子のみ(status: draft)
> 実装根拠に使用できません(AGENTS.md §0)。**Phase 2着手前**までに[[09.2_WorkPackage_Template]]相当の水準へ実体化します。
> 現時点で確定している内容は、リンク先の`baseline`文書を参照してください。

## 1. 概要

Loading、Empty、Partial、Offline、Permission denied、Conflict、Expired、Retryを共通化。

## 2. 目的

- UI State and Error Modelを実装・検証可能にする

## 3. 対象範囲

- Skeleton
- Empty action
- Inline error
- Incident banner
- Conflict resolution

## 4. 対象外

- 原因不明のErrorだけ表示

## 5. 基本方針

- **Role-specific**：PortalとOpsの情報密度を分ける
- **Consistency**：Token/Common componentを利用
- **Accessibility**：Keyboard/Focus/ErrorをAcceptanceへ

## 6. 成果物

- Screen requirement
- State inventory
- Mock/Prototype
- E2E/UAT scenario

## 7. 受入基準

- [ ] 主要TaskとStateが網羅
- [ ] 用語がSOLVIと一致
- [ ] Accessibility観点がある

## 8. リスクと対策

- **Information overload**：Primary actionを上位固定
- **Mock drift**：Requirement/Testを実装正本とする
