## 1. 概要

WCAG 2.2 AA相当、簡潔な日本語、Keyboard、Screen reader、Error recoveryを設計。

## 2. 目的

- Accessibility and Content Designを実装・検証可能にする

## 3. 対象範囲

- Contrast
- Focus
- Label
- Error summary
- Plain language

## 4. 対象外

- 色だけでStatus伝達

## 5. 基本方針

- **Role-specific**：PortalとOpsの情報密度を分ける
- **Consistency**：Token/Common componentを利用
- **Accessibility**：Keyboard/Focus/ErrorをAcceptanceへ

## 6. 成果物

- Screen requirement
- State inventory
- Mock/Prototype
- E2E/UAT scenario
