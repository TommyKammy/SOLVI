## 重要な注意

- モックアップ内の日付・氏名・会社名・数値は**すべてサンプル**であり、実装要件ではない。
- **モックアップと要求が食い違う場合は要求とテストが正**。相違点は各モックアップノートの正誤表([[11.9_Admin_Settings_Mockup]]、[[11.7_Admin_Dashboard_Mockup]]、[[11.8_Ticket_Management_Mockup]])に記載する。
- 画像の再生成を行う場合は、正誤表の項目を解消してから差し替え、MANIFESTのハッシュを更新する。
