## 1. 概要

採用済みSOLVI Portal。主要行動を「リクエストを送る」「インシデントを報告」の二つに集約。

## 2. 目的

- User Portal Mockupを実装・検証可能にする

## 3. 対象範囲

- Hero search
- 2 primary cards
- FAQ/進行中/お知らせ
- Recent tickets

## 4. 対象外

- 管理者Menu、詳細KPI

## 5. 基本方針

- **Role-specific**：PortalとOpsの情報密度を分ける
- **Consistency**：Token/Common componentを利用
- **Accessibility**：Keyboard/Focus/ErrorをAcceptanceへ

## 6. 成果物

- Screen requirement
- State inventory
- Mock/Prototype
- E2E/UAT scenario

## 7. 受入基準

- [ ] 主要TaskとStateが網羅
