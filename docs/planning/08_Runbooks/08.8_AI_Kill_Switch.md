# AI Kill Switch Runbook

> [!warning] この文書は骨子のみ(status: draft)
> 実装根拠に使用できません(AGENTS.md §0)。**該当機能のPhase着手前(Gate条件に演習が含まれるものはGate前)**までに[[09.2_WorkPackage_Template]]相当の水準へ実体化します。
> 現時点で確定している内容は、リンク先の`baseline`文書を参照してください。

## 1. Purpose

AI品質・安全・費用問題時にSOLVI Assistを停止する。

## 2. Trigger

Monitoring alert、User report、Security detection、Periodic drill、Change failureのいずれか。

## 3. Procedure

1. Feature flag off
2. Queue drain
3. Fallback確認
4. User notice
5. Cause review
6. Re-enable gate

## 4. Evidence

- Detection、Response、Recovery時刻
- Environment、Organization、Ticket/Workflow/Command ID
- CommandとResult（Secretを除く）
- Decision maker、Approval、External case ID
- Recovery validationとResidual risk

## 5. Completion

- 正常性とData integrityを確認する。
- Duplicate execution、越権、Evidence欠落がないことを確認する。
- 必要なPIR、Risk、ADR、WPを更新する。
