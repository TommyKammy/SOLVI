# Evidence Index

## Naming

`evidence/<WP-ID>/<YYYYMMDD-HHMM>/<artifact>`

Vaultには巨大Logを直接置かず、Summary、Hash、Storage URI、Commit SHAを記録する。

| Type | Required metadata |
|---|---|
| Test Run | command, environment, commit, result, duration |
| UI Evidence | role, viewport, scenario, screenshot |
| Security | threat/abuse ID, input, expected denial, result |
| External API | tenant, scoped client, correlation, redacted response |
| Migration | source/target/reject count, hash, sample |
| Human Sign-off | reviewer, role, date, decision, conditions |
| Restore Drill | backup ID, target, RPO/RTO, data verification |
