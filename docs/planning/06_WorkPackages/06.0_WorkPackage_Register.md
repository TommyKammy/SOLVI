## Issue化規則

- 1 WPを1 GitHub Issueへ変換する([[06.3_GitHub_Issue_Conversion_Guide]])。
- WP IDをIssue title、Branch、PR、Evidenceに使用する。`Depends on`は実Issue番号へ置換する。
- Scope外の変更はWPを膨らませず、後続IssueまたはADRにする。
- Story PointはCodex処理時間ではなく、Review・Verificationを含む複雑性である。13点のWPは着手前に分割を検討する。

## Status

`Not started → Ready → In progress → Review → Validated → Done`

Identity、Security、Executor、MigrationのWPはHuman sign-offなしでDoneにしない。Gate直前のWP(GATE系)はProduct Owner + Security Reviewerの合意が必要。
