## 運用規則

- 新しいDecisionは[[09.1_ADR_Template]]を使用する。
- 既存ADRの決定内容を上書きせず、後継ADRでSupersedeし、双方のSupersedes/Superseded by欄を更新する。
- Architecture・永続化・Identity・Security・Executor境界に関わる変更はADRなしに実施しない(AGENTS.md §1.9)。
