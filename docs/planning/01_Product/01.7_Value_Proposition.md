# Value Proposition

> [!warning] この文書は骨子のみ(status: draft)

## 1. 概要

価値はライセンス削減だけでなく、承認済み業務を安全に自動化し、ID・資産・変更データを改善へ接続することにある。

## 2. 目的

- 利用者、IT担当、管理者、経営・監査の価値を区別する

## 3. 対象範囲

- 利用者：入口簡素化と透明な進捗
- IT担当：定型処理削減と検索性
- 管理者：内製拡張と統制
- 経営：費用・生産性・リスク可視化

## 4. 対象外

- 単なる安価代替という位置付け

## 5. 基本方針

- **Measure outcomes**：工数、自己解決率、再発率を測る
- **Own the control plane**：承認・実行・監査を自社所有する

## 6. 成果物

- 正本Markdown
- 関連要求・UI・WPへのリンク

## 7. 受入基準

- [ ] 会話履歴なしで理解できる
- [ ] スコープと非対象が矛盾しない
- [ ] SOLVI用語体系と一致する

## 8. リスクと対策

- **Scope creep**：新規要求はPhase/Gateへ割り当てる
- **Naming drift**：SOLVI名称体系を自動検査する
