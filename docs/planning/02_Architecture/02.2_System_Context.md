# System Context

> [!warning] この文書は骨子のみ(status: draft)
> 実装根拠に使用できません(AGENTS.md §0)。**該当機能のPhase着手前**までに[[09.2_WorkPackage_Template]]相当の水準へ実体化します。

## 1. 概要

SOLVIの利用者、外部システム、信頼境界、責務外を定義する。

## 2. 目的

- 外部責任と内部責任を混同しない

## 3. 対象範囲

- 利用者/IT担当/承認者/監査者
- Okta/Entra/Graph
- 通知チャネル
- Intune/CrowdStrike/AWS
- AI provider

## 4. 対象外

- 人事マスタの置換

## 5. 基本方針

- **Identity authority**：基本IdentityはIdPが権威
- **Asset authority**：属性ごとにSourceを定義
- **Writes**：外部書込みはExecutor経由

## 6. 成果物

- Architecture view
- 責務・依存・禁止経路
- 関連ADR/WP

## 7. 受入基準

- [ ] Trust boundaryが明確
- [ ] 要求と矛盾しない
- [ ] Issueへ分解可能

## 8. リスクと対策

- **Overengineering**：初期はModular Monolithを維持
- **Boundary violation**：Architecture/Security testで検出
