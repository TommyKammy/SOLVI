# AI Architecture

> [!warning] この文書は骨子のみ(status: draft)
> 実装根拠に使用できません(AGENTS.md §0)。**該当機能のPhase着手前**までに[[09.2_WorkPackage_Template]]相当の水準へ実体化します。
> 現時点で確定している内容は、リンク先の`baseline`文書を参照してください。

## 1. 概要

SOLVI Assistは分類、要約、検索、回答案、Change Risk案を提供するが、業務状態・承認・実行を所有しない。

## 2. 目的

- AI価値と安全境界を両立

## 3. 対象範囲

- RAG
- Prompt registry
- Evaluation
- Citation
- PII minimization
- Feature flag

## 4. 対象外

- AI自律承認
- AIによる直接実行
- 無検証自動公開

## 5. 基本方針

- **Advisory only**：人間または決定論ルールが確定
- **Traceability**：Model/Prompt/Context/Resultを記録
- **Kill switch**：AI停止時もITSM継続

## 6. 成果物

- Architecture view
- 責務・依存・禁止経路
- 関連ADR/WP

## 7. 受入基準

- [ ] Trust boundaryが明確
- [ ] 要求と矛盾しない
- [ ] Issueへ分解可能

## 8. リスクと対策

- **Overengineering**：初期はModular Monolithを維持
- **Boundary violation**：Architecture/Security testで検出
