# Workflow and Outbox Architecture

> [!warning] この文書は骨子のみ(status: draft)
> 実装根拠に使用できません(AGENTS.md §0)。**該当機能のPhase着手前**までに[[09.2_WorkPackage_Template]]相当の水準へ実体化します。
> 現時点で確定している内容は、リンク先の`baseline`文書を参照してください。

## 1. 概要

長時間待機する承認と外部実行を、State Machine、Transactional Outbox、Workerで処理する。

## 2. 目的

- 取りこぼし、重複、同期Timeoutを防ぐ

## 3. 対象範囲

- WorkflowDefinition
- WorkflowRun
- Step
- Outbox
- Retry
- Timeout
- Cancel

## 4. 対象外

- HTTP request内の長時間外部処理

## 5. 基本方針

- **Initial engine**：DB State Machine
- **Upgrade seam**：複雑性閾値でTemporal再判断
- **Delivery**：at-least-once + idempotency

## 6. 成果物

- Architecture view
- 責務・依存・禁止経路
- 関連ADR/WP

## 7. 受入基準

- [ ] Trust boundaryが明確
- [ ] 要求と矛盾しない
- [ ] Issueへ分解可能

## 8. リスクと対策

- **Overengineering**：初期はModular Monolithを維持
- **Boundary violation**：Architecture/Security testで検出
