# Integration Architecture

> [!warning] この文書は骨子のみ(status: draft)
> 実装根拠に使用できません(AGENTS.md §0)。**該当機能のPhase着手前**までに[[09.2_WorkPackage_Template]]相当の水準へ実体化します。
> 現時点で確定している内容は、リンク先の`baseline`文書を参照してください。

## 1. 概要

外部連携をConnector AdapterとWebhook contractで統一し、Vendor差分をDomainから隔離する。

## 2. 目的

- Okta/Entra/Asset sourceを交換可能にする

## 3. 対象範囲

- Connector interface
- Contract test
- Rate limit
- Error mapping
- Webhook signature

## 4. 対象外

- 外部SDK型のDomain流入

## 5. 基本方針

- **Adapters**：Vendor差分を局所化
- **Versioning**：API変更を契約テストで検知
- **Observability**：外部request IDをReceiptへ保存

## 6. 成果物

- Architecture view
- 責務・依存・禁止経路
- 関連ADR/WP

## 7. 受入基準

- [ ] Trust boundaryが明確
- [ ] 要求と矛盾しない
- [ ] Issueへ分解可能

## 8. リスクと対策

- **Overengineering**：初期はModular Monolithを維持
- **Boundary violation**：Architecture/Security testで検出
