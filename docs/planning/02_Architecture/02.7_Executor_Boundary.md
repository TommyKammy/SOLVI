# Privileged Executor Boundary

> [!warning] この文書は骨子のみ(status: draft)
> 実装根拠に使用できません(AGENTS.md §0)。**該当機能のPhase着手前**までに[[09.2_WorkPackage_Template]]相当の水準へ実体化します。
> 現時点で確定している内容は、リンク先の`baseline`文書を参照してください。

## 1. 概要

SOLVI Runは型付きCommand、Allowlist、事前条件、冪等性、Receiptを持つ独立した特権境界である。

## 2. 目的

- CoreやAI侵害時の被害範囲を制限

## 3. 対象範囲

- Command schema
- Policy
- Idempotency
- Precondition
- Receipt
- Retry
- Compensation

## 4. 対象外

- 任意HTTP/Shell
- 自由入力Resource ID

## 5. 基本方針

- **Input**：署名済み・期限付きCommand
- **Output**：Receipt必須
- **Network**：必要APIだけへEgress

## 6. 成果物

- Architecture view
- 責務・依存・禁止経路
- 関連ADR/WP

## 7. 受入基準

- [ ] Trust boundaryが明確
- [ ] 要求と矛盾しない
- [ ] Issueへ分解可能

## 8. リスクと対策

- **Overengineering**：初期はModular Monolithを維持
- **Boundary violation**：Architecture/Security testで検出
