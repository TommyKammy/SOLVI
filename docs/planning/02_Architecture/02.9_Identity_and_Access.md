# Identity and Access Architecture

> [!warning] この文書は骨子のみ(status: draft)
> 実装根拠に使用できません(AGENTS.md §0)。**該当機能のPhase着手前**までに[[09.2_WorkPackage_Template]]相当の水準へ実体化します。
> 現時点で確定している内容は、リンク先の`baseline`文書を参照してください。

## 1. 概要

OIDCで認証し、SCIMでライフサイクルを同期し、IdP GroupをSOLVI Roleへマッピングする。

## 2. 目的

- 認証とProvisioningを分離

## 3. 対象範囲

- Provider config
- Identity link
- RoleBinding
- JIT optional
- SCIM
- Delegation

## 4. 対象外

- 通常利用のローカルPassword

## 5. 基本方針

- **Stable key**：issuer+subject/externalId
- **Deprovision**：active=falseで履歴保持
- **Multi-org**：複数RoleBindingで兼務・出向

## 6. 成果物

- Architecture view
- 責務・依存・禁止経路
- 関連ADR/WP

## 7. 受入基準

- [ ] Trust boundaryが明確
- [ ] 要求と矛盾しない
- [ ] Issueへ分解可能

## 8. リスクと対策

- **Overengineering**：初期はModular Monolithを維持
- **Boundary violation**：Architecture/Security testで検出
