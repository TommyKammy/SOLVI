# Branch and PR Strategy

> [!warning] この文書は骨子のみ(status: draft)
> 実装根拠に使用できません(AGENTS.md §0)。**該当Phase着手前**までに[[09.2_WorkPackage_Template]]相当の水準へ実体化します。
> 現時点で確定している内容は、リンク先の`baseline`文書を参照してください。

## 1. 概要

1 WPを1 Codex thread、1 branch、1 PRに対応させる。

## 2. 目的

- Branch and PR Strategyを実行可能な規則へ落とす

## 3. 対象範囲

- Protected main
- Short-lived branch
- CODEOWNERS
- PR Template

## 4. 対象外

- 巨大PR、複数WP混在

## 5. 基本方針

- **Human review**：Identity/Security/Executorは二重Review
- **Evidence**：Command/ResultをPRへ
- **Migration**：CompatibilityとRollback説明

## 6. 成果物

- Plan/Checklist
- WP Acceptanceへの反映

## 7. 受入基準

- [ ] 例外と禁止事項が明確
- [ ] 会話履歴なしで実行可能

## 8. リスクと対策

- **Process drift**：GateでEvidence確認
- **Environment drift**：Clean-host/Stage再検証
