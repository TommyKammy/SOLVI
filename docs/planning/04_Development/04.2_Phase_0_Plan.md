| 項目 | 値 |

## 1. このPhaseで達成すること

- ADR 18件のaccepted化と矛盾解消
- 脅威モデルの脅威↔要求↔テスト接続
- 要求101件の3点整合とRTM
- リポジトリとAGENTS.mdの配置、P0 Issue化
- UI正誤表と画面マトリクス
- Freshserviceベースライン取得

## 3. このPhaseでやらないこと

- 実装コードの先行作成(WP-P1以降)
- Phase 1以降のWPの実体化(各Phase開始2週間前に行う)

## 4. Exit条件

[[04.22_Gate_Definitions]]の **Gate 0** のチェックリストをすべて満たすこと。判定者はProduct Owner + Security Reviewer。

- 未達項目があるまま次Phaseの高リスク作業へ着手しない。
- Critical/Highの未解決が0件であること。
- 対象WPがすべて[[04.19_Definition_of_Ready_and_Done]]のDoDを満たすこと。

## 5. リスクと対策

- **スケジュール圧力**: Gate未達なら期間を延ばす。合格条件を緩めない([[04.1_Master_Roadmap]]§3)。
- **依存の未完了**: 着手条件を満たさないWPは着手しない(AGENTS.md §2.2)。
- **見積り乖離**: Phase完了時に計画と実績のポイント/期間を記録し、次Phaseの見積りへ反映する。
