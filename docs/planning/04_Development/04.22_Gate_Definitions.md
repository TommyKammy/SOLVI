# Gate Definitions

各Gateの**合否チェックリスト・必要Evidence・判定者・不合格時アクション**の正本。Phase計画(04.2〜04.11)の「Exit criteria」は本書を参照する。チェック項目は原則すべて二値判定(Yes/No)とし、判定不能な項目はNoとして扱う(fail closed)。

## 共通規則

- 判定者: Product Owner + Security Reviewer(Gate B以降はこの2名の合意必須。同一人物の兼任は不可。兼任せざるを得ない体制の場合は外部レビューアを充てる)。
- Evidence: `06.2_Evidence_Index`の命名規則に従いGate Decision Recordへリンクする。
- 不合格時: 該当Phaseを延長し、未達項目をWP化して再判定日を設定する。**未達のまま次Phaseの高リスク作業(特権・SCIM・移行)へ着手しない。**
- 条件付き合格: Critical/High以外の未達に限り、期限付きリスク受容(99.3へ登録)で通過可。

## Gate D: 外部ID連携(ローカル検証完了 → 外部IdP接続)

**このGateは [[ADR-0019_Local_Authentication_For_Development]] により新設した。**

SOLVIをローカル環境・ローカルアカウントで構築し、基本機能の検証を終えてから
外部IdPへ接続する。テナントを入手した時点ではなく、**ローカル検証が完了した時点**で着手する。
順序を逆にすると、認証の問題と業務機能の問題が同時に発生し、切り分けができなくなる。

### 着手前提(これが揃うまで [[WP-P1-IDM-003]] を開始しない)

| # | 前提 |
|---|---|
| GD-0a | Gate 1 の全条件を達成している(ローカル認証で判定) |
| GD-0b | Phase 2 の業務機能がローカルアカウントで一通り検証済み |
| GD-0c | Okta または Entra ID のテストテナントが払い出されている |

### 合格条件

| # | 合格条件 | Evidence |
|---|---|---|
| GD-1 | OIDCログインがテストテナントで動作し、issuer/audience/state/nonce/expの各不正ケースが**拒否される**ネガティブテスト通過(`FR-IDM-001`) | CIテスト結果 |
| GD-2 | identity link(issuer + subject)が一意に確立し、**別issuerの同一subjectが別人として扱われる**(`FR-IDM-002`) | テスト結果 |
| GD-3 | IdP側でのユーザ無効化がSOLVIのセッション失効へ`FR-IDM-008`のSLA内で反映される | 実測記録 |
| GD-4 | **ローカル認証が本番構成で起動を拒否する**ことを、本番相当の環境変数で確認済み | 起動ログ |
| GD-5 | ローカルアカウントが全て破棄され、`identity`に`urn:solvi:local`の行が残っていない | DB検査結果 |
| GD-6 | IdP障害時の手順([[08.4_OIDC_Outage_Runbook]])が実手順化され、机上演習済み | 演習記録 |

### 中止条件

GD-4 が未達の場合、外部IdP接続を進めない。
ローカル認証の経路が本番で生きたまま外部IdPを繋ぐと、
**強い認証を追加したつもりで弱い認証を残す**という最悪の構成になる。

## Gate 3 / 5 / 6 / 7 / 8(要約 — 該当Phase開始2週間前までに詳細化する)

- **Gate 3(Knowledge)**: 権限外記事が検索・直接URL・AI経由のいずれでも取得不能。日本語検索の評価セット(50問)でTop-5正解率80%以上。Freshservice記事移行試行の件数照合一致。
- **Gate 5(SCIM)**: [[03.7_Identity_OIDC_SCIM_Requirements]]のSCIM準拠マトリクスの「準拠」宣言項目がOkta/Entra両実機のContract Testで全通過。再送・重複externalId・PATCH方言の収束テスト通過。JML(入社/異動/退職/兼務)UATシナリオ全通過。
- **Gate 6(Asset)**: CSV再取込の冪等収束、Intune同期の差分適用とSource追跡、重複候補の人間確認フロー動作。
- **Gate 7(Change)**: Type別必須項目とBackout Plan欠落拒否、承認前Scheduled不可、カレンダー競合検出の動作。CABパイロット1サイクル完了。
- **Gate 8(AI)**: 評価データセットでの回帰基準(要約の重大欠落率<5%、引用正確性>95%、Injection誘導拒否率100%)通過。Kill Switch演習。プロンプト/モデル/参照/回答の追跡がAI Traceで再現可能。
