# CI CD Quality Gates

> [!warning] この文書は骨子のみ(status: draft)
> 実装根拠に使用できません(AGENTS.md §0)。**該当Phase着手前**までに[[09.2_WorkPackage_Template]]相当の水準へ実体化します。

## 1. 概要

Lint、Type、Unit、Integration、Architecture、E2E、Secret、Dependency、Migration、Clean-hostを必須化する。

## 2. 目的

- CI CD Quality Gatesを実行可能な規則へ落とす

## 3. 対象範囲

- Required checks
- Cache
- Artifact
- Image scan
- Migration test

## 4. 対象外

- Test skipでGreenにすること

## 5. 基本方針

- **Fail closed**：必須Check失敗でMerge不可
- **Pinned dependencies**：Lockfile/Image固定
- **Evidence retention**：Gate Log保存

## 6. 成果物

- Plan/Checklist
- WP Acceptanceへの反映

## 7. 受入基準

- [ ] 例外と禁止事項が明確
- [ ] 会話履歴なしで実行可能

## 8. リスクと対策

- **Process drift**：GateでEvidence確認
- **Environment drift**：Clean-host/Stage再検証
