# Phase 4 Plan — カタログ・承認・特権自動化

| 項目 | 値 |
|---|---|
| Phase | P4 |
| 期間(初期見積り) | 8〜11週間 |
| Points | 84 |
| 着手条件 | Gate 1およびGate A合格。[[02.16_Executor_Command_Contract]]がbaselineであること |
| Exit | [[04.22_Gate_Definitions]] Gate B |

## 1. このPhaseで達成すること

- カタログとフォーム定義の版管理
- 承認統制(SoD・自己承認防止・再承認・取消)
- Workflow/Outbox
- Executorの契約検証・冪等・Receipt・Kill Switch
- Okta/Entraの低リスク操作

## 3. このPhaseでやらないこと

- 高リスク操作(アカウント作成等)のAllowlist追加 — Gate B実績後に別途判断
- 汎用Workflowデザイナー(恒久的Non-Goal)

## 4. Exit条件

[[04.22_Gate_Definitions]]の **Gate B** のチェックリストをすべて満たすこと。判定者はProduct Owner + Security Reviewer。

- 未達項目があるまま次Phaseの高リスク作業へ着手しない。
- Critical/Highの未解決が0件であること。
- 対象WPがすべて[[04.19_Definition_of_Ready_and_Done]]のDoDを満たすこと。

## 5. リスクと対策

- **スケジュール圧力**: Gate未達なら期間を延ばす。合格条件を緩めない([[04.1_Master_Roadmap]]§3)。
- **依存の未完了**: 着手条件を満たさないWPは着手しない(AGENTS.md §2.2)。
- **見積り乖離**: Phase完了時に計画と実績のポイント/期間を記録し、次Phaseの見積りへ反映する。
