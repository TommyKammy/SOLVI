# Phase 5 Plan — SCIM 2.0

| 項目 | 値 |
|---|---|
| Phase | P5 |
| 期間(初期見積り) | 5〜7週間 |
| Points | 50 |
| 着手条件 | Gate B合格 |
| Exit | [[04.22_Gate_Definitions]] Gate 5 |

## 1. このPhaseで達成すること

- SCIM Discovery/認証とトークン運用
- User CRUD/PATCH
- Group/Membership
- Okta/Entra実機のContract Test
- JML・兼務・出向のUAT

## 3. このPhaseでやらないこと

- SCIM準拠マトリクス外の機能(ETag/Bulk/汎用filter/sort)

## 4. Exit条件

[[04.22_Gate_Definitions]]の **Gate 5** のチェックリストをすべて満たすこと。判定者はProduct Owner + Security Reviewer。

- 未達項目があるまま次Phaseの高リスク作業へ着手しない。
- Critical/Highの未解決が0件であること。
- 対象WPがすべて[[04.19_Definition_of_Ready_and_Done]]のDoDを満たすこと。

## 5. リスクと対策

- **スケジュール圧力**: Gate未達なら期間を延ばす。合格条件を緩めない([[04.1_Master_Roadmap]]§3)。
- **依存の未完了**: 着手条件を満たさないWPは着手しない(AGENTS.md §2.2)。
- **見積り乖離**: Phase完了時に計画と実績のポイント/期間を記録し、次Phaseの見積りへ反映する。
