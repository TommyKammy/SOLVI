# Engineering Test Strategy

## 1. 原則

- 境界(Organization/Role/Executor)の異常系を最優先でテストする。
- Clock/Random/外部応答を制御し決定的に実行する。Fixtureは合成データのみ(実データ・実PII禁止)。
- 各WPのAcceptance Criteriaは本書のテストレイヤーIDを参照する。失敗テストの削除・skipによるゲート通過は禁止(AGENTS.md)。
