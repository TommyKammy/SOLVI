| 項目 | 値 |
|---|---|
| Phase | P8 |
| 期間(初期見積り) | 5〜7週間 |

## 1. このPhaseで達成すること

- 分類・要約
- 権限を尊重したRAGと引用
- Prompt Injection防御
- 評価データセットとリリースゲート
- AI可観測性・コスト管理・Kill Switch

## 3. このPhaseでやらないこと

- AIによる承認・実行(恒久的Non-Goal。ADR-0007)

## 4. Exit条件

[[04.22_Gate_Definitions]]の **Gate 8** のチェックリストをすべて満たすこと。判定者はProduct Owner + Security Reviewer。

- 未達項目があるまま次Phaseの高リスク作業へ着手しない。
- Critical/Highの未解決が0件であること。
- 対象WPがすべて[[04.19_Definition_of_Ready_and_Done]]のDoDを満たすこと。

## 5. リスクと対策

- **スケジュール圧力**: Gate未達なら期間を延ばす。合格条件を緩めない([[04.1_Master_Roadmap]]§3)。
- **依存の未完了**: 着手条件を満たさないWPは着手しない(AGENTS.md §2.2)。
- **見積り乖離**: Phase完了時に計画と実績のポイント/期間を記録し、次Phaseの見積りへ反映する。
