# Phase 2 Plan — チケット管理MVP

| 項目 | 値 |
|---|---|
| Phase | P2 |
| 期間(初期見積り) | 6〜8週間 |
| Points | 60 |

## 1. このPhaseで達成すること

- Portal起票からOps解決までの縦切り
- 状態機械としての遷移制御
- 内部メモの分離
- 添付の安全な取扱い
- SLO・監視・オンコール体制
- 限定パイロットの開始判断

## 3. このPhaseでやらないこと

- カタログ・承認(Phase 4)
- ナレッジ(Phase 3)
- 特権自動化

## 4. Exit条件

[[04.22_Gate_Definitions]]の **Gate A** のチェックリストをすべて満たすこと。判定者はProduct Owner + Security Reviewer。

- 未達項目があるまま次Phaseの高リスク作業へ着手しない。
- Critical/Highの未解決が0件であること。
- 対象WPがすべて[[04.19_Definition_of_Ready_and_Done]]のDoDを満たすこと。

## 5. リスクと対策

- **スケジュール圧力**: Gate未達なら期間を延ばす。合格条件を緩めない([[04.1_Master_Roadmap]]§3)。
- **依存の未完了**: 着手条件を満たさないWPは着手しない(AGENTS.md §2.2)。
- **見積り乖離**: Phase完了時に計画と実績のポイント/期間を記録し、次Phaseの見積りへ反映する。
