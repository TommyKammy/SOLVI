# Maintainability Requirements

## 適用範囲

このノートはMaintainability Requirementsの正本であり、関連Module、WP、Testの入力となる。

## 要求

| ID | Requirement | Detail | Priority | Acceptance |
|---|---|---|---|---|
| NFR-MNT-001 | 保守性 | Module境界をArchitecture Testで保護 | Must | 禁止依存検査がCIで実行され違反0件 |
| NFR-MNT-002 | 再現性 | Clean environmentでBuild/Test | Must | クリーンホストで起動〜全テスト通過が手順書どおり再現できる |

## 設計・検証規則

- Must要求は対象Gate前にEvidenceを残す。
- UIだけでなくAPI、Worker、直接URL、外部APIを含めて検証する。
- Should要求を延期する場合は理由、代替策、再評価時期を記録する。
