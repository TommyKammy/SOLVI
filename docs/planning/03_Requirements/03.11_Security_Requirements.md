# Security Requirements

## 適用範囲

セキュリティ非機能要求の正本。各要求は[[02.14_Threat_Model]]の脅威IDへ対応する。

## 要求

| ID | Requirement | Detail | 対応脅威 | Priority | Acceptance |
|---|---|---|---|---|---|
| NFR-SEC-001 | Organization境界 | アプリ認可+RLSの二層防御([[02.18_Organization_Data_Model_and_RLS]]) | T-01 | Must | 越境自動テスト全拒否(G1-2/G1-3) |
| NFR-SEC-002 | 最小権限 | Connector別最小スコープ表+四半期アクセスレビュー | T-11,T-20 | Must | スコープ表の第三者レビュー記録+レビュー実施記録(GB-7) |
| NFR-SEC-003 | 監査非改ざん | append-only+日次外部アンカー([[02.17_Audit_Event_Catalog]]§3) | T-19 | Must | DB拒否テスト+アンカー照合(G1-4/G1-5) |
| NFR-SEC-004 | Secret保護 | secret scan CI+ログredaction+AI prompt送信禁止 | T-22 | Must | scan/redactionテスト通過(G1-6) |
| NFR-SEC-005 | 入力防御 | スキーマ検証、DTOホワイトリスト、SSRF対策(送信先allowlist+プライベートIP帯遮断)、ファイル検証 | T-03,T-18 | Must | 契約テスト+セキュリティテスト通過 |
| NFR-SEC-006 | オブジェクトレベル認可 | 同一Org内でも所有・役割に基づくオブジェクト単位認可(IDOR/BOLA防止)。存在秘匿は404優先 | T-02 | Must | 権限外直接ID指定の自動テスト全拒否 |
| NFR-SEC-007 | Webhook/Callback認証 | 受信Webhook: HMAC署名+timestamp±5分+リプレイ拒否。送信: 署名付与+失敗時の再送制御 | T-17 | Must | 署名不正・再送・時刻ずれの拒否テスト |
| NFR-SEC-008 | 供給網管理 | lockfile固定、依存脆弱性scan(Critical/High検出でCI fail)、コンテナベースイメージのdigest固定、依存追加はレビュー必須 | T-21 | Must | CI設定+検査ログ(G1-6) |
| NFR-SEC-009 | バックアップ保護 | バックアップ/エクスポートの暗号化(KMS)+アクセス制御+取得・復元の監査記録 | T-23 | Must | 権限外アクセス拒否検査+Restore Drill記録 |
| NFR-SEC-010 | Command Replay防止 | Executor Commandの署名・有効期限(≤15分)・nonce一回性([[02.16_Executor_Command_Contract]]§1) | T-09 | Must | 再送・期限切れ・署名改ざんの拒否テスト(GB-1) |

## 検証規則

- 本表のMust要求は該当Gate(G1/GB)の合格条件そのものであり、リスク受容による免除は不可。
- 新脅威が[[02.14_Threat_Model]]に追加された場合、対応する要求IDを本表へ追加してからWP化する。
