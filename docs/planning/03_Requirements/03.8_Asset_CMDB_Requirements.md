# Asset CMDB Requirements

## 適用範囲

このノートはAsset CMDB Requirementsの正本であり、関連Module、WP、Testの入力となる。

## 要求

| ID | Requirement | Detail | Priority | Acceptance |
|---|---|---|---|---|
| FR-AST-001 | Asset Model | PC/Server/VM/NW/Mobile/SaaS等 | Must | Type別必須属性の欠落レコードが登録できない |
| FR-AST-002 | CSV Import | Validate/Preview/Diff/Re-run | Must | 不正行が隔離リストへ出力され、正常行のみ取り込まれる |
| FR-AST-003 | Reconciliation | 外部IDで重複防止 | Must | 同一CSVを2回取り込んでAsset件数と内容が変化しない |
| FR-AST-004 | External Sync | Intune等から定期同期 | Must | 同期ごとにSource・件数・成功/失敗・実行時刻が記録される |
| FR-AST-005 | Relations | AssetとUser/Ticket/Change関連 | Should | 関係の追加・削除が履歴として参照できる |

## 設計・検証規則

- Must要求は対象Gate前にEvidenceを残す。
- UIだけでなくAPI、Worker、直接URL、外部APIを含めて検証する。
- Should要求を延期する場合は理由、代替策、再評価時期を記録する。
