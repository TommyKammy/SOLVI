# Requirements Baseline

## 1. 目的と正本関係

要求の**登録簿(レジストリ)**。IDの一意性・優先度・担当Module・詳細正本・追跡先を管理する。

- **各要求の本文(Detail)と受入基準の正本はカテゴリ別ノート**(下表「詳細正本」列)。本書には複製しない。
- 追跡(WP/ADR/Test/Gate)の正本は[[03.18_Requirements_Traceability_Matrix]]。
- 本書・カテゴリ別ノート・RTMの3点は同一変更で同期する(WP-P0-REQ-004のDoD)。
