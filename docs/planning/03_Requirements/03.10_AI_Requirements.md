# AI Requirements

## 適用範囲

このノートはAI Requirementsの正本であり、関連Module、WP、Testの入力となる。

## 要求

| ID | Requirement | Detail | Priority | Acceptance |
|---|---|---|---|---|
| FR-AI-001 | Ticket Summary | 長い会話を要約 | Must | 評価セットで重大な事実欠落率5%未満 |
| FR-AI-002 | Classification | Category/Priority/Assignee候補 | Must | AI分類が自動適用されず、採否がイベントとして記録される |
| FR-AI-003 | RAG Answer | 許可Knowledgeから回答案 | Must | 回答に引用記事IDと版が必ず表示され、引用なし回答が0件 |
| FR-AI-004 | Answerability | 根拠不足時回答不能 | Must | 根拠不足時に「わからない」を返す率が評価セットで100% |
| FR-AI-005 | Prompt Injection | 入力/文書命令をData扱い | Should | 注入コーパスでの誘導成功0件 |
| FR-AI-006 | Evaluation | Model/Prompt/Dataset版管理 | Should | リリース前に評価セットの回帰を実行し基準未達なら公開されない |
| FR-AI-007 | Kill Switch | AIを即時停止 | Should | AI停止時にチケット・承認・実行の各操作が完了できる |

## 設計・検証規則

- Must要求は対象Gate前にEvidenceを残す。
- UIだけでなくAPI、Worker、直接URL、外部APIを含めて検証する。
- Should要求を延期する場合は理由、代替策、再評価時期を記録する。
