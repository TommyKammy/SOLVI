# Knowledge Requirements

## 適用範囲

このノートはKnowledge Requirementsの正本であり、関連Module、WP、Testの入力となる。

## 要求

| ID | Requirement | Detail | Priority | Acceptance |
|---|---|---|---|---|
| FR-KNW-001 | 記事Lifecycle | Draft/Review/Published/Retired | Must | 公開操作がknowledge管理者に限定され、全版が復元可能 |
| FR-KNW-002 | 公開範囲 | Organization/Role/全社公開 | Must | 権限外ユーザの検索結果0件かつ直接URLが404 |
| FR-KNW-003 | 全文検索 | 日本語Title/Body/Tag検索 | Must | 評価セット50問でTop-5正解率80%以上 |
| FR-KNW-004 | Ticket連携 | 記事引用・関連付け | Must | 解決時に参照した記事IDと版がチケット履歴に残る |
| FR-KNW-005 | 記事評価 | 役立った/役立たない | Should | 評価が閾値未満の記事が一覧で抽出できる |

## 設計・検証規則

- Must要求は対象Gate前にEvidenceを残す。
- UIだけでなくAPI、Worker、直接URL、外部APIを含めて検証する。
- Should要求を延期する場合は理由、代替策、再評価時期を記録する。
