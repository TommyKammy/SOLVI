# Work Package Template

1 WP = 1 GitHub Issue = 1 branch = 1 PR。13ポイント以上のWPは着手前に分割を検討する(同一WP ID内で複数PRに分ける場合は§11に順序を明記する)。

```markdown
---
project: SOLVI
doc_id: "WP-Pn-XXX-nnn"
title: "<成果を表す短い日本語>"
category: "06_WorkPackages"
type: "workpackage"
status: "baseline"      # 実体化前は draft
version: "0.1.0"
created: "YYYY-MM-DD"
updated: "YYYY-MM-DD"
owner: "SOLVI Product Team"
tags: ["workpackage", "pn"]
source_of_truth: true
implementation_status: "not-started"
---

## 1. Purpose
このWPが完了すると何ができるようになるか。前後のWPとの関係。

## 2. Requirement IDs
`FR-XXX-001`, `NFR-XXX-002`  ← RTMと一致させる

## 3. Dependencies
[[WP-...]]  ← 06.0台帳と一致させる

## 4. Scope / Allowed Paths
- `path/to/dir/`   ← 実在するパスのみ。ここ以外を変更させない

## 5. Out of Scope
- <このWPでやらないこと。後続WP名または「恒久的にNon-Goal」を明記>

## 6. Deliverables
- <成果物。「Policy」のような単語ではなく、何がどこにできるかを書く>

## 7. Acceptance Criteria
検証可能な条件のみ。各項目は「誰が/何をすると/何が起きる」が判定できる粒度にする。
- [ ] <条件>

禁止: 「適切に動作する」「十分にテストされている」のような判定不能な記述。

## 8. Verification and Evidence
### テスト(→ [[04.16_Test_Strategy]])
- TL-nn(<何を検証するか>)
### Evidence
- <保存する証跡>
Evidenceは`evidence/<WP-ID>/<YYYYMMDD-HHMM>/`へ。Command・Environment・Commit SHA・Result・Timestampを含める。

## 9. Security and Audit
- <このWPで守るべき境界・生成すべき監査イベント・Secretの扱い>
- <該当する脅威ID(02.14)があれば明記>

## 10. Rollback / 失敗時の扱い
<不具合時にどう戻すか。Migration down、feature flag、サービス停止など。
 「戻せない」場合はその旨と代替(前進修復)を書く>

## 11. Codex app Prompt
WP固有の指示を書く。全WP共通の定型文だけにしない。最低限含めるもの:
- 読むべき正本(このWPと参照設計文書)
- 具体的な作業手順
- このWPで**やってはいけないこと**
- 完了時の報告項目

## 12. Definition of Done
- [ ] §7をすべて満たす / §8のテスト通過とEvidence保存
- [ ] Migrationとロールバック方針、既存データ互換の説明
- [ ] 関連ドキュメント(API定義・Runbook・RTM)の更新
- [ ] 未解決のCritical/Highがない
- [ ] <Riskに応じたsign-off: Identity/Security/Executor/MigrationはSecurity Reviewer必須>
- [ ] Execution Logへ追記

## 13. Execution Log
| Date | Actor | Commit/PR | Result | Evidence | Notes |
|---|---|---|---|---|---|
| - | - | - | Not started | - | - |
```

## 実体化の運用

- 各PhaseのWPは**当該Phase開始の2週間前までに**このテンプレートの水準へ実体化する(受入基準の具体化、WP固有Prompt、Rollback記述)。
- 実体化前のWPは`status: draft`とし、Issue化しない([[00.4_Document_Governance]])。
